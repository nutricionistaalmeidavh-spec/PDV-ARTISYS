# Finance P8-P12 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fechar o ciclo Venda → Financeiro com migration resiliente, QA de integração e integridade, fluxo Playwright completo e gate de instalador/smoke.

**Architecture:** Manter a projeção financeira orientada a eventos e idempotente já criada em P0-P7. P8 endurece a migration v13 sem mudar dados existentes; P9/P10 consolidam os contratos de negócio em Node/SQLite real; P11 valida a jornada pela UI; P12 incorpora esses gates ao `qa:user:all`, antes do smoke do instalador.

**Tech Stack:** Node.js >=22, `node:test`, `node:sqlite`, Electron, Playwright via `@artisys/qa`, PowerShell/NSIS para smoke instalado.

**Spec:** roadmap aprovado P0-P12 e `docs/superpowers/specs/2026-09-17-finance-p5-p7-design.md` para os contratos de origem/idempotência.

## Global Constraints

- Preservar bancos e lançamentos financeiros existentes.
- Não somar Vendas + Caixa + Financeiro como receitas independentes.
- Manter `sourceType + sourceId + sourceLineKey` como identidade financeira de negócio.
- Manter `eventId + effectKey` como idempotência de processamento de evento.
- Não alterar `main`; trabalhar em `feat/qa-user-all`.
- O instalador continua sendo gerado antes do QA, conforme fluxo de entrega atual.
