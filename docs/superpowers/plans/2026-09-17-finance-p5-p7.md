# Financeiro P5–P7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Completar P5–P7 do roadmap Sale → Finance com filtros/navegação, relatórios semanticamente separados e idempotência de origem reforçada.

**Architecture:** O serviço financeiro enriquecido passa a resolver contexto de venda/devolução sem duplicar dados em schema. A UI P5/P6 entra como enhancer separado. A idempotência P7 fica encapsulada em `createSourceEntry`, usada pelos efeitos financeiros existentes.

**Tech Stack:** Node.js 22, CommonJS, SQLite/`node:sqlite`, EventBus/outbox/effect store, Electron renderer, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-17-finance-p5-p7-design.md`

## Global Constraints

- Não criar nova migration.
- Não apagar histórico financeiro.
- Não alterar totais comerciais da venda.
- Não somar Venda + Caixa + Financeiro como três receitas.
- Preservar P0–P4 e lançamentos manuais.
- Usar a branch `feat/qa-user-all`.
